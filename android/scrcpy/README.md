# scrcpy Android server

RustEmuDroid for Windows includes the unmodified Android server published by Genymobile with scrcpy v5.0.1. It handles input in the installed BlueStacks player. Windows Desktop Window Manager supplies the picture.

- [Official release and server download](https://github.com/Genymobile/scrcpy/releases/tag/v5.0.1)
- [Upstream source](https://github.com/Genymobile/scrcpy/tree/v5.0.1/server)

## Shared Vulkan memory on the Radeon 780M

Windows users can enable **Shared Vulkan memory (Radeon 780M)** in emulator settings for their Android 17 Google Play x86-64 profile. Select the host GPU and **AMD Radeon 780M Graphics**, enable the checkbox, then save and restart Android. The option is off by default and requires an SDK emulator that exposes the corresponding feature flag.

On the tested Ryzen 9 8945HS with Android Emulator 37.3.10, the standard Vulkan configuration exposed a 256 MiB heap for CPU-visible allocations. Enabling the option also exposed a 15.86 GiB shared heap. FPS WW2 URP then loaded Level 1 on Vulkan at 1600 × 900 with Max quality, Very High antialiasing and real-time lights. Two samples in the starting trench recorded 37.77 and 37.95 Android presentations/s. The original configuration stopped during level loading with a Unity Vulkan allocation error.

The Linux and Windows packages include the same desktop version. The memory option targets the Windows SDK runtime and its selected Android profile.

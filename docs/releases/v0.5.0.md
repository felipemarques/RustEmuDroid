## Test the BlueStacks Pie64 data disk

The Windows ZIP and Linux archive now include a read-only storage diagnostic in the `tools` directory. Open the included guide, point the tool at offline copies of the validated `fastboot.vdi` and `Data_orig.vhdx`, and select a new output directory. On Windows the PowerShell entry point runs QEMU inside WSL. No disk images are included in the downloads.

On QEMU 8.2.2, the original Pie64 kernel recognized the VirtIO SCSI controller, found the ext4 partition at `/dev/sdb1`, mounted it read-only at `/data` with journal replay disabled, and unmounted it. The diagnostic reports these milestones in `result.json`. It uses the factory data seed, and does not inspect installed games or saves.

The independent VM still stops during BlueStacks host configuration. A separate hardware check found that standard VGA exposes a VESA framebuffer, while neither standard VGA nor the tested VirtIO GPU provided the DRM device expected by the image's composer. On Windows, **Open BlueStacks** remains the available way to play games in an existing BlueStacks instance.

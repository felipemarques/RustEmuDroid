# RustEmuDroid v0.20.0

In a smaller native player window, open **Settings → Graphics**, enable **Fit video frames to the window**, and save. The Android guest keeps rendering at its configured resolution. The desktop requests an image sized for the visible game area, including Windows display scaling. You can change the option during play. Full-resolution delivery is the default.

PNG screenshots, MP4 recording and fullscreen use the native Android resolution. GIF, animated JPEG XL and replay also read native frames, then fit the exported animation within 720 × 720 while preserving its aspect ratio.

A development build ran the same SuperTuxKart replay four times on the RTX 5070 Ti at 90 Hz, twice per stream size. Matching the stream to a 1034 × 582 pixel game area raised the panel's processing rate from 74.02 to 79.85 frames/s. The game averaged 82.97 and 84.39 FPS, respectively. Android presentations rose from 80.53 to 82.71/s. The game rendered at 1600 × 900 throughout.

# RustEmuDroid v0.19.0

You can now take a PNG screenshot inside the Windows BlueStacks preview. Click the camera button in the preview toolbar or press **Ctrl+Shift+S** while playing. The screenshot uses the Android display's resolution and is saved in the same captures folder as native RustEmuDroid screenshots. The preview shows the filename when the save finishes.

Enable **Android Debug Bridge (ADB)** in the selected BlueStacks instance and reconnect the preview to enable the camera button. The launcher requests the image only when you take a screenshot. It waits for pending image exports when you close the Rust window.

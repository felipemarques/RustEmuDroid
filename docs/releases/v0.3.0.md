## Game controls

- **Edge scroll** pans a game when the pointer approaches the edge of the Android image. Drop the control where the game accepts a drag, then adjust the horizontal and vertical margins and speed. On Android 17, the virtual touchscreen recorded the expected strokes and releases. Moving into a letterbox bar or taking focus away stopped edge input.
- **Tilt** maps a held key or button to rotation around the Android device's X, Y or Z axis. Releasing the binding restores the previous pose. On the tested Android 17 profile, a +15° binding moved the X axis from −4.75° to +10.25° and back to −4.75°. Both controls are available from the floating editor with **Ctrl+Shift+A**. [Controls guide](https://github.com/felipemarques/RustEmuDroid/blob/v0.3.0/README.md)

## Compatibility and performance

- The optional Windows/WSL and Linux Pie64 diagnostic mounted a verified copy of the Android system without attaching the user data disk. The original BlueStacks configuration stopped at `android_id is empty`. Opening a registered instance through the BlueStacks player remains the working way to use its games. [Boot diagnostic](https://github.com/felipemarques/RustEmuDroid/blob/v0.3.0/docs/bluestacks-lab.md#opt-in-system-mount)
- In the measured PUBG MOBILE inventory sequence, the longest pause between new game buffers was 2.17 seconds. The game thread ran for 1.32 seconds during that interval. A separate desktop frame-copy comparison produced comparable guest cadence across all four runs. [Measurements and test conditions](https://github.com/felipemarques/RustEmuDroid/blob/v0.3.0/docs/game-testing.md)

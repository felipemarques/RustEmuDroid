## Install Android from RustEmuDroid

Open **Install Android runtime or image** on the startup screen or in Settings. Choose **Original** for Android 15 AOSP or **Google Play** for Android 17 with the Play Store. The installer shows the package size, destination and Google's license text before download. After installation, select **Use and start this profile**.

Windows and Linux x86-64 downloads come directly from Google's package catalog. The installer verifies each archive against the catalog and installs the engine, ADB and the selected system image in the user's data directory. The second image shares the installed tools and has its own Android app data.

The terminal command `runtime-setup --image original` shows the download plan and terms. The [English manual](https://github.com/felipemarques/RustEmuDroid/blob/v0.13.0/README.md#first-time-setup-in-rustemudroid) includes the setup screen and command options.

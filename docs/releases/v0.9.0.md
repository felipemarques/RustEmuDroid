## Run with an installed Kemu or a portable runtime

On Windows, users with Kemu already installed can open `rustemudroid.exe` directly. The Original profile can use Kemu’s own Android 16 image, QEMU engine and ADB with Host or Auto graphics. A fresh-profile Windows test confirmed Android boot in 47.7 seconds and verified the RustEmuDroid Home activity. The test used the installed Kemu files and a private ADB server.

On Windows and Linux, a `runtime/` directory next to the executable can supply Android Emulator, Platform-Tools and an x86-64 system image. The release archives contain the desktop client and the diagnostic tools. Supply the runtime separately. Existing SDK installations and explicit `--sdk` paths are still supported. Open the desktop executable without arguments to start the interface, or use `doctor` to see the selected engine and ADB paths.

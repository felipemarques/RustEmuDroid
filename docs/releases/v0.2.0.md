## Game controls

Click the keyboard in the sidebar to open the game controls menu. You can switch schemes, toggle mappings, and preview key labels at your preferred opacity. Select **Controls editor** or press **Ctrl+Shift+A** to edit over the game. Opening either panel keeps the Android image at the same scale.

- Drag the D-pad onto a virtual stick or steering wheel. Click each direction to bind it, drag the center to move it, and drag the corner handle to resize it.
- Place touch controls and gestures from the palette, including a mouse-wheel swipe. You can move the editor to the opposite edge to reach controls underneath.
- Save a scheme for the current game. Existing game profiles carry forward.

**Help → Shortcuts** lists the keyboard shortcuts and when each one works. The desktop UI and manuals are available in Brazilian Portuguese, US English and Spanish.

## BlueStacks on Windows

**Open BlueStacks** launches the installed player. The PowerShell helper in the source checkout runs a separate diagnostic on local copies of the Pie64 disks. In testing the kernel started and then stalled in SCSI error handling. Booting this image to Android inside RustEmuDroid remains experimental.

## Game control profiles

Open a game, click the keyboard icon and choose **Manage profiles**. Start with an empty profile or duplicate the current layout. Give the copy a name, choose **Edit controls**, move its controls and click **Save**. For example, keep separate profiles for driving and walking in the same game.

Switch layouts under **Game profile** in the keyboard menu. RustEmuDroid remembers the selection separately for each Android game. Existing mappings carry over. The manager also supports renaming, deleting and sharing layouts as JSON.

# RustEmuDroid v0.14.0

On Windows, choose **Open BlueStacks → Use this window** or run `rustemudroid bluestacks mirror --instance Pie64` to display the live Android surface from an installed BlueStacks 5 instance. Windows DWM presents the picture at the player's aspect ratio. Keep the original window restored. Disconnecting leaves the player running.

Enable Android Debug Bridge in BlueStacks advanced settings for mouse touch and drag, scrolling, basic keyboard input, volume and Android navigation. This requires a local ADB client from the managed runtime or Android Platform Tools. With ADB off, the picture remains available. The native Android session retains the game control profiles, recordings and panel FPS counter. [Windows instructions](../../README.md#open-an-installed-bluestacks-instance-on-windows)

## Android startup after an emulator crash

The embedded player could stay on the loading screen after a previous VM crash. The Android SDK sometimes opened a separate crash-report dialog before Android or ADB was available. A user could only resume startup by finding and dismissing that dialog.

RustEmuDroid now disables the SDK crash reporter for the embedded player and headless runs. The change applies to the emulator process launched for that session. Its boot log is still available in the selected profile for local diagnosis.

## Keep the default PUBG driver when Linux Vulkan is running on the CPU

RustEmuDroid skips the automatic PUBG MOBILE ANGLE preference on Android 17 Google Play when the Linux emulator boot log confirms that the selected Vulkan device is a CPU renderer. This covers setups such as WSLg with hardware OpenGL ES and llvmpipe Vulkan. An existing per-app driver preference still applies.

To check the active backend, look for `Selecting Vulkan device` in the session log and match that name to the reported device type. See [Android 17 graphics on Linux](https://github.com/felipemarques/RustEmuDroid/blob/main/docs/linux-runtime.md#select-the-radeon-780m-for-opengl-es-in-wslg) for the tested setup.

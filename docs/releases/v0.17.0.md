# RustEmuDroid v0.17.0

The embedded BlueStacks player on Windows now uses RustEmuDroid's per-game control schemes. With ADB enabled in BlueStacks, open a game, click the keyboard icon and choose **Controls editor**. Place a D-pad over the game's joystick and a button over an action. Press **Save**, click the game and hold both bindings to move and use the action together. **Ctrl+Shift+A** opens the editor directly. **Ctrl+Shift+P** cycles through that game's saved schemes.

Each BlueStacks instance has its own RustEmuDroid mapping file. When Android switches apps, the input worker releases held mapped contacts and selects the scheme for the newly focused package. The editor uses a still image of the game and preserves the fitted image area. During play, Windows DWM displays the live player. Keyboard-only schemes can respond to key events without polling a gamepad every 16 ms. The native Android session also supports live binding hints and tilt sensors.

On the restored Pie64 instance, Android received two contacts while the test held a D-pad direction and an action key. Both cleared when focus changed. The optimized Windows client also completed two SuperTuxKart Black Forest replays on the RTX 5070 Ti. With the preview focused and a 60 FPS player cap, the game reported **59.992 FPS** with an empty control profile directory and **59.993 FPS** with the kart profile present. Both runs received one focus click and used the game's automatic replay.

## PUBG MOBILE startup fix

PUBG MOBILE 4.7.0 could close during startup on the Android 17 Google Play x86-64 image. Crash logs showed the guest EGL driver failing while presenting a frame.

On eligible boots with host or automatic GPU rendering, RustEmuDroid selects Android's built-in ANGLE driver for `com.tencent.ig`. This runs the game's OpenGL ES calls over Vulkan. The launcher checks Vulkan support and preserves existing per-app driver preferences. This setting lives in the Android profile and survives a restart.

Verified on a GeForce RTX 5070 Ti using the existing PUBG installation and game data. The game passed the KRAFTON splash and downloaded resources. The Android 16 Kemu profile retains its separate ARM translation setting.

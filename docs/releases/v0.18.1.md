# RustEmuDroid 0.18.1

When the verified BlueStacks player exits on Windows, RustEmuDroid closes its preview and returns to the launcher. This also works in view-only mode, in full screen and while the control editor is open. Reopen the instance to reconnect.

RustEmuDroid now recognizes emulator and ADB packages installed by its runtime installer in a custom directory selected with `--sdk`. A fresh Original profile uses Android 15 AOSP there even when the same folder also contains Android 17 Google Play or Kemu is installed on Windows. Setup can add the other image to that managed folder. If automatic discovery encounters an incomplete installation, the diagnostic includes a command for opening the built-in setup.

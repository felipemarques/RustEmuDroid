# RustEmuDroid v0.15.1

Fixed gamepad input when multiple controllers are connected. A mapped button stays held until every controller holding that button releases it. Each analog stick takes both axes from one controller, and another engaged controller can take over when the first returns to its dead zone or disconnects.

Unplugging a controller cancels its unfinished touch gestures, including quick casts, while preserving held keyboard input and controls from other connected controllers. The offline regressions cover shared buttons, stick handoff and disconnection during a quick cast. [Regression tests](../../src/display/mapping.rs)

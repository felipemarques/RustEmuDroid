# RustEmuDroid v0.18.0

To compare the same game on two Android runtimes, open **Settings → FPS counter**, choose **Android game surface** and click **Save**. The title bar counts new frames presented by Android for the game in the foreground. The setting applies immediately and also works in the embedded BlueStacks player on Windows when ADB is connected. Existing profiles keep their previous counter setting.

The counter waits for consecutive measurements from the same SurfaceView. A dash appears while a game is opening, when the foreground app has no identifiable game surface, or when timing data is unavailable. A stationary game surface can show zero. Choose **Rust panel** to see how many frames the native client processes for drawing. Choose **Off** to hide the counter.

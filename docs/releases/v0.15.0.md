# RustEmuDroid v0.15.0

On Windows, the installed BlueStacks preview now has a **Rotate** button in its toolbar. It requests rotation on the Android display through the same authorized connection used for touch and navigation. The preview cancels any held touch before sending the request and resumes coordinate input when the Android display and preview geometry agree.

Android and the active app can keep their current orientation. When Android confirms the original display size, the preview resumes input at that size. [BlueStacks preview setup](../../README.md#open-an-installed-bluestacks-instance-on-windows) · [Input regression tests](../../src/ui/blue_mirror/tests.rs)

In a live Windows test on a restored Pie64 instance, the Settings screen rotated from 1600 × 900 to 900 × 1600 and back. The fitted preview changed from 1072 × 603 to 339 × 603 pixels and back. Android screenshots confirmed both sizes. A subsequent tap opened Network & internet, and two Back actions returned to SuperTuxKart. Closing the Rust window preserved the game and removed the temporary input server. The fixture used programmatic egui input.

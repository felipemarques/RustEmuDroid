# RustEmuDroid v0.21.0

On Windows, select **Install APK** in an embedded BlueStacks session and choose a local `.apk` file. The button uses the same file picker as the native Android session and requires an active ADB connection to the selected player. The toolbar shows the result after Android processes the file.

The installer checks that the selected player and ADB transport still match after the dialog closes. Choosing a file leaves the preview responsive, and the selected Android instance stays open after installation. Android still applies its package-signature and update rules.

A separate Windows DWM experiment showed a live SuperTuxKart replay inside a Rust window while it covered the Qt game area. The first four runs reached about 90 game FPS with either viewer. The results identify the GPUs used and report Windows CPU time separately.

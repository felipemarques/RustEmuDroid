# RustEmuDroid v0.14.1

On Windows, a held touch in the BlueStacks preview is cancelled when Help or Settings covers the game, the window loses focus, or the preview changes size during the gesture. Resizing from the window border keeps the drag in Windows. Using Back during a held touch cancels the contact before navigating.

We verified the change on an installed Pie64 instance. With the network settings row held, the test opened Help and released the button. Android Settings retained focus for 1.115 seconds across five observations. A fresh tap on the same row opened Network & internet, and two Back actions returned to SuperTuxKart. The test used egui input events in a real Windows launcher. Closing it left the source windows in place, and an external check confirmed removal of the temporary control-server files and process.
